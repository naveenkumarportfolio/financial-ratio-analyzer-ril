
# Financial Ratio Analyzer – Reliance Industries Limited (RIL)

An Excel-based financial analysis project developed to evaluate the financial performance of Reliance Industries Limited (RIL) using financial ratios, an interactive dashboard, and automated financial insights.

This project connects financial statement data with ratio calculations and visual reporting to make financial performance easier to analyse and understand.

---

## 1. Project Overview

The Financial Ratio Analyzer is designed to assess a company's financial health and performance across four key areas:

- Profitability
- Liquidity
- Leverage
- Efficiency

The model uses linked financial inputs, formula-driven calculations, and automated commentary to analyse financial performance across multiple financial years.

**Company Analysed:** Reliance Industries Limited (RIL)  
**Tool Used:** Microsoft Excel  
**Project Type:** Financial Analysis & Financial Modelling  
**Reporting Period:** FY2023–FY2026

---

## 2. Project Objectives

The main objectives of this project are:

- Analyse financial statements using key financial ratios.
- Evaluate profitability and operational performance.
- Assess short-term liquidity and financial obligations.
- Understand the company's debt and capital structure.
- Compare financial performance across multiple years.
- Develop an interactive financial performance dashboard.
- Generate automated financial insights and identify potential risk areas.

---

## 3. Workbook Structure

The Excel workbook contains five worksheets:

| Worksheet | Description |
|---|---|
| Financial Inputs | Organises income statement, balance sheet, and supporting financial information. |
| Ratio Calculations | Calculates financial ratios using linked Excel formulas. |
| Ratio Analysis | Presents calculated ratios with automated interpretations. |
| Dashboard | Provides a visual overview of financial performance. |
| Financial Insights | Generates financial commentary, performance comparisons, and potential risk flags. |

---

## 4. Financial Ratios Analysed

The project covers 10 key financial ratios.

### Profitability Ratios
- Gross Profit Margin
- EBITDA Margin
- Net Profit Margin
- Return on Assets (ROA)
- Return on Equity (ROE)

### Liquidity Ratios
- Current Ratio
- Quick Ratio

### Leverage Ratios
- Debt-to-Equity Ratio
- Debt Ratio

### Efficiency Ratios
- Asset Turnover Ratio

## 7. How to Use the Workbook

1. Download the Excel workbook from this repository.
2. Open the workbook using Microsoft Excel.
3. Navigate to the Financial Inputs worksheet.
4. Review the financial data and reporting periods.
5. Explore the Ratio Calculations worksheet to understand the formulas.
6. Review Ratio Analysis for calculated ratios and interpretations.
7. Open the Dashboard to explore financial performance.
8. Visit Financial Insights to review automated commentary and potential risk indicators.

**Note:** Avoid overwriting formula cells when updating financial inputs.

## 9. Project Limitations & Assumptions

- The analysis depends on the financial figures entered in the workbook.
- FY2024 is the baseline year for income-statement-based year-on-year comparisons.
- Some average-balance calculations require prior-year opening balances.
- Automated commentary is based on predefined Excel formulas and thresholds.
- Financial insights should be reviewed alongside the company's annual reports and other relevant disclosures.
